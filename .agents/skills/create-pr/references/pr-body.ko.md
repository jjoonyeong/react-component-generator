# 국문 PR 본문 템플릿

아래 틀을 실제 변경에 맞게 채운다. 안내 주석을 제거하고, 선택 항목은 관련 있을 때만 남긴다. 기본 양언어 본문에서는 이 내용 다음에 영문 템플릿을 이어 붙인다.

```markdown
## 한국어

### 변경 요약
<!-- 해결하는 문제와 변경 후 동작을 1~2문장으로 작성한다. -->

### 주요 변경
<!-- 리뷰에 필요한 핵심 변경만 적는다. 단순 변경이면 요약에 합친다. -->

### 검증
<!-- 실제 실행한 명령과 결과 또는 수행하지 못한 검증과 이유를 적는다. -->

### 영향 및 유의사항
<!-- 선택: 호환성, 마이그레이션, 알려진 한계 등 검토에 필요한 사항. -->

### 관련 이슈
<!-- 선택: 확인된 이슈 링크. 자동 종료 키워드는 의도된 경우에만 사용한다. -->
```
